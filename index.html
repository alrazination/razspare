🌐 Online Shop Link

Share one link with anyone. They see your parts, prices (incl. GST) and availability — live — and can place an order. Orders arrive under Online Orders. Buying prices, suppliers and exact stock counts are never shown.

One-time setup (about 5 minutes)
  1. Open your Google Sheet → menu Extensions → Apps Script.
  2. Delete everything in the editor, press Copy script below, paste it, and click Save.
  3. Click Deploy → New deployment → gear icon → Web app.
  4. Set Execute as: Me and Who has access: Anyone → Deploy. Allow the permissions (Google shows an “unverified app” warning for your own script — choose Advanced → Go to project).
  5. Copy the Web app URL, paste it above, press Save, then Test connection.

If you ever edit the script later, redeploy with Deploy → Manage deployments → Edit → New version; the URL stays the same.
